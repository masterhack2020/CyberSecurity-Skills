# Contributing to CyberSecurity-Skills

Thank you for contributing.

## Contribution Principles

- Keep content focused on defensive cybersecurity and authorized security research.
- Provide clear documentation and examples.
- Avoid publishing secrets, credentials, malware samples, or unauthorized exploitation material.

## Pull Requests

Before submitting a pull request:

1. Describe the purpose of the change.
2. Explain security impact if applicable.
3. Keep commits focused and documented.

## Quality Requirements

Contributions should be technically accurate, reproducible, and useful for cybersecurity learning.
