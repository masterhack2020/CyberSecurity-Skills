# CyberSecurity-Skills

An open-source AI-powered Cyber Security Skills Framework for Claude Code, Codex, Cursor, and GitHub Copilot.

## Overview

CyberSecurity-Skills is a structured knowledge framework designed to help security researchers, developers, and learners organize cybersecurity skills, workflows, and defensive practices with the assistance of modern AI coding tools.

## Goals

- Build a practical cybersecurity learning framework
- Organize security skills by domain
- Improve security research workflows using AI assistants
- Encourage responsible and authorized security testing

## Security Domains

Planned skill categories:

- Reconnaissance & OSINT
- Web Application Security
- Network Security
- Cloud Security
- Malware Analysis
- Digital Forensics
- Incident Response
- Threat Intelligence
- Secure Coding
- Security Automation

## AI Assistant Support

The framework is designed to work with:

- Claude Code
- OpenAI Codex
- Cursor
- GitHub Copilot
