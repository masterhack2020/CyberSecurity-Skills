# Security Policy

## Purpose

This repository is intended for cybersecurity education, defensive research, and authorized security testing.

## Reporting Security Issues

Please report security vulnerabilities privately instead of opening a public issue.

Include:
- Description of the vulnerability
- Steps to reproduce
- Security impact
- Suggested mitigation (if available)

## Responsible Use

Only use security tools, techniques, and knowledge against systems where you have explicit authorization.

The maintainers are not responsible for unauthorized use of the materials in this repository.
