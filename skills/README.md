# CyberSecurity Skills Framework

This directory contains structured cybersecurity skill modules.

## Skill Module Format

Each skill should contain:

```
skill-name/
├── skill.md
├── checklist.md
├── examples/
├── tools.md
└── references.md
```

## Categories

- reconnaissance
- web-security
- network-security
- cloud-security
- malware-analysis
- digital-forensics
- incident-response
- threat-intelligence
- secure-coding
